TITLE: Credential Stuffing

CATEGORY: Authentication Security

DESCRIPTION:
Credential stuffing is an attack technique in which previously obtained username and password combinations are attempted against another service.

COMMON LOG PATTERNS:
- Many authentication attempts
- Attempts involving multiple user accounts
- Repeated failures from one or several source addresses
- High authentication frequency
- Multiple accounts targeted within a short period

INVESTIGATION:
Look for repeated authentication failures involving multiple accounts and identify common source addresses or unusual request patterns.

DEFENSIVE GUIDANCE:
Multi-factor authentication, rate limiting, monitoring, password hygiene, and detection of unusual authentication patterns can reduce risk.
